# Imagens de compartilhamento (1200×630)

JPEGs usados em `og:image`, `twitter:image` e no campo `image` do schema
`Article` das páginas de conteúdo. São recortes das mesmas fotos do Burst
usadas nos cards (ver `../blog/CREDITOS.md` e `../segmentos/CREDITOS.md`).

Formato JPEG de propósito: WhatsApp, LinkedIn, Facebook e X aceitam JPEG sem
risco; WebP ainda não é universal nesses rastreadores.

O mapa página → imagem fica em `content/imagens.mjs`. Para trocar a imagem de
uma página, substitua o `.jpg` mantendo o nome (1200×630, ~80 KB).
